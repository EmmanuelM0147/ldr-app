# Demo video script

Record a 2–4 minute walkthrough of the live app (or local Compose). Publish the link in the README under **Demo video**.

## Suggested takes (screen + voice)

1. **Problem (15s)** — Long-distance couples already chat elsewhere; Closer is the shared plan: visits, budget, check-ins, memories.
2. **Register + pair (45s)** — Create two accounts (two browsers/profiles). Owner creates a space, copies invite code; partner pastes and joins. Show the partner-joined notice / home.
3. **Visit + check-in (45s)** — Add a visit (From/To). Save today’s check-in with a mood + short note. Show both on the partner’s Check-in tab.
4. **Memories + notifications (30s)** — Upload a photo memory; open the bell inbox.
5. **Presence / settings (30s)** — Toggle “free to talk” (Compose or AWS for reliable WS). Mention delete space + password change signs you out.
6. **Close (15s)** — Point at the public URLs and the GitHub repo.
